# Yukon Yeti — the Turner Pinball family

Session start 2026-08-13. Patch **0232-turner-pinball.yaml**.

## User decisions

- **Scope: all five Turner Pinball models** (user, 2026-08-13), not just Yukon Yeti — the README line predates this. Titles: Yukon Yeti (2026), Merlin's Arcade (Arcade + Legendary Editions, 2025), Ninja Eclipse (Arcade + First Editions, 2024). All five were near-bare: no credits, features, statuses, formats, systems or descriptions anywhere.
- **Rename `yukon-yeti` → Legendary Edition naming** (user, 2026-08-13), matching the maker's own name for the sole edition ("Yukon Yeti™ Legendary Edition™" — the base game itself; the All-In Package is an upgrades bundle, not an edition) and the family's naming convention ("Merlin's Arcade (Legendary Edition)"). Musketeers' Classic Edition rename is the precedent.

## The company

- Legal entity: **Turner Logic, LLC** — every turnerpinball.com page footer reads "© 2026 Turner Logic, LLC" + "Deep in the Heart of Texas, USA".
- **City: Boerne, TX.** turnerlogic.com/contact (first-party) gives the mailing address "215 West Bandera Road, Ste. 114-814, Boerne, TX 78006" and phone (210) 901-9955 — the **same phone number** turnerpinball.com/contact lists, tying the two sites to one entity. Corroboration: Turner Logic's Facebook lists Boerne TX; Kineticist (2026-03-19) says the facility is "in the San Antonio area" (Boerne is San Antonio metro). Note the Ste. number reads as a mailbox, so this is the registered/mailing city, asserted with a note.
- Turner Logic predates the pinball operation (San Antonio app-dev shop, founded 2012, Chris Turner ex-Lockheed). Turner Pinball "founded in late 2022" (maker About page). **Chris Turner bought Deeproot Pinball's IP at the March 2022 bankruptcy auction, keeping Yukon Yeti and Merlin's Arcade** (Kineticist). Timeline (maker About): whitewood at TPF Spring 2023 → pre-production at Chicago Expo Fall 2023 → production Ninja Eclipse at TPF Spring 2024, deposits taken → first deliveries Chicago Expo Fall 2024, First Edition run sold out → Merlin's announced TPF Spring 2025, ships late Summer 2025 → Yukon Yeti announced TPF Spring 2026.

## Conflicts and their resolutions

- **Yukon Yeti audio credits.** Kineticist (updated 2026-04-29): "There is no dedicated sound designer or composer credited"; PN reveal (03-18): sound "overseen and edited by Chris Turner". The maker's own page (fetched 2026-08-04) announces **Chris Granner leading sound direction** and **Adam Gubman as composer and sound designer**. Chronology resolves it: the outlet statements predate the announcement; the maker's current site wins (Houdini precedent). Chris Turner's reveal-era audio editing is not asserted as a sound credit.
- **Wizard mode count (Yukon).** Maker page + PN press release: "12 base modes plus 2 wizard modes". Kineticist's rules section describes three (Northern Lights, Super Northern Lights, Secret Stash). Maker wins; mode counts aren't catalog fields anyway — affects description wording only.
- **Merlin's Arcade Edition quantity.** Kineticist: "800 Arcade units". Maker FAQ: "not numbered or limited"; PN: "no restriction on production". Maker + PN agree — **no Arcade quantity asserted**; the 800 stays unused.
- **Ninja Eclipse First Edition price** moved ($9,777 on the 2023 reserve page → $6,994 on the 2025 page). Not a catalog field; noted for the record.

## Key structural facts

- **Ninja Eclipse Arcade Edition was never produced.** The catalog row (OPDB "Pro edition") describes an edition the maker discusses only as future-possible: "We may offer an Arcade Edition™... at some point in the future." First Edition (100 units, sold out) is the only Ninja Eclipse ever made. Asserted `production_status: announced` on the Arcade Edition with the FAQ quote and a note.
- **Merlin's lineage**: Arcade Edition is the base (cheaper, unlimited), Legendary is `variant_of` it — the standing cheaper-less-limited-is-base rule, and the same shape Ninja Eclipse already has in the catalog (First `variant_of` Arcade).
- **White Water lineage is not representable as an edge**: the ModelRelationship vocabulary is closed (conversion, conversion_kit, copy, retheme — DB check constraint), and "unofficial sequel/spiritual successor" is none of them. Recorded in the Yukon Yeti description with cites instead.
- **No System created**: no source names Turner's control system or platform. PinAccess™ is a connected-play/app service, not evidenced as the machine's operating system. Sought (updates page, ruleset, articles) and not found.
