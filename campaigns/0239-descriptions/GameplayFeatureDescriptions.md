# Gameplay feature descriptions

## Scope

There's different "classes" of gameplay features, such as:

- a base general feature like "standup targets", which need full encyclopedia-quality descriptions
- a variant of a feature, like "6-bank standup targets", which probably just need a one-sentence gloss
- a manufacturer branded name for a feature, which probably just need a one-sentence gloss

LMK what's most efficient and ergonomic for you, if we should classify these up front so that we don't waste time writing full descriptions for things that don't warrant it.

## Format

Gameplay features start with a description of the feature (obviously). It'd be great to follow with story of the feature, such as historical significance, interesting anecdotes about the feature, notable models with the feature, who invented it, era of the feature etc. Don't get too formulaic, though: different features probably want different treatments. Find some previous data patch examples and let's decide on what consitutes a good description before we start writing a bunch. I suspect we'll want to write a few good ones as examples before doing the rest.

## Citations

Gameplay features are more general knowledge than many other types of records. Feel free to rely on your training data and general knowledge to describe the gameplay feature, without citing. However, _do_ use cites (or catalog data) when referencing more specific facts (like the date a feature was introduced, or specific anecdotes about the feature).
